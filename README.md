# TCG Multi-Platform Listing Tool

## Project Overview
Comprehensive tool for managing TCG card listings across multiple platforms, starting with Trade Me integration.

## Phase 1: Trade Me TCG Listing Assistant (MVP)
Web-based SaaS that lets NZ sellers create high-quality Trade Me listings for Pokémon and MTG singles quickly.

### Key Features
- Card search and price conversion (NZD)
- Draft listing generation with validation
- Trade Me OAuth integration
- Manual confirmation before publishing
- Connected account settings
- Listing history tracking

## Architecture
- **Frontend:** Next.js with TypeScript
- **Backend:** Firebase Cloud Functions  
- **Database:** Firebase Firestore
- **Auth:** Firebase Auth (Google)
- **APIs:** Trade Me, Collectr (planned)
